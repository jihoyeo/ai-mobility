# 머신러닝이란

## 머신러닝의 정의
- 데이터에서 학습하도록 컴퓨터를 프로그래밍하는 방법
- 미첼(1997) — 경험 E로 작업 T의 성능 P가 향상되면 학습
  - 제주 예측: T 속도 예측, E 과거 운행 기록, P MAE
- 데이터 보유와 학습은 다름 — 기준은 성능 P의 향상
> 학생에게 버스 도착시간 예측을 T·E·P에 대입해 보게 한다.

## 규칙 기반의 한계
- 규칙 기반: 사람이 조건을 나열 → 조건이 늘수록 유지보수 비용 증가
  - 시간대 평균 → 요일 추가 → 도로 등급 추가 → 강우 추가
- 머신러닝: 패턴을 데이터에서 찾고 새 데이터에 적응
- 유리한 경우: 규칙이 긴 문제, 유동적 환경, 대량 데이터
> 규칙 작성 루프가 데이터·훈련·평가 루프로 바뀌는 구조를 판서로 그린다.

## 지도 학습과 비지도 학습
- 지도 학습: 정답 레이블이 있는 데이터로 학습
  - 분류(스팸 여부)와 회귀(속도·가격)
- 비지도 학습: 레이블 없이 데이터의 구조를 발견
  - 군집, 차원 축소, 이상치 탐지
- 이 과목의 문제는 모두 회귀 — 통행속도, 도착시간
> 특성·예측 변수·속성은 같은 말. 로지스틱 '회귀'는 이름과 달리 분류기.

## 그 밖의 학습 방식
- 준지도 학습: 일부만 레이블 — 구글 포토의 인물 묶기
- 자기 지도 학습: 데이터에서 레이블을 스스로 생성
- 강화 학습: 보상 신호로 정책 학습 — 알파고
- 배치 학습과 온라인 학습: 한 번에 학습 vs 점진적 학습
  - 배치 모델의 성능 저하 — 모델 부패, 데이터 드리프트
> 세 축은 트리가 아니라 조합 가능한 좌표축. 학생들이 자주 트리로 오해한다.

## 사례 기반과 모델 기반
- 모델 기반: 경향을 식으로 요약
- 사례 기반: 가까운 이웃과 비교
- 교체 비용: 두 줄

```python
import pandas as pd
from sklearn.linear_model import LinearRegression

df = pd.read_csv("lifesat.csv")   # 1인당 GDP, 삶의 만족도
X = df[["gdp_per_capita"]].values
y = df["life_satisfaction"].values

model = LinearRegression()        # 모델 기반
model.fit(X, y)
print(model.predict([[37_655.2]]))       # (결과) [[6.30]]

from sklearn.neighbors import KNeighborsRegressor
model = KNeighborsRegressor(n_neighbors=3)   # 사례 기반
model.fit(X, y)
print(model.predict([[37_655.2]]))       # (결과) [[6.33]]
```
> OECD 삶의 만족도 예제. '모델'의 세 가지 의미(종류·구조·훈련 결과)는 시험 단골.

# 좋은 모델의 조건

## 나쁜 데이터의 네 가지
- 양 부족 — 문제가 복잡할수록 필요한 데이터 증가
- 대표성 없음 — 1936년 미국 대선 여론조사의 표본 편향
  - 샘플링 잡음은 양의 문제, 샘플링 편향은 방법의 문제
- 품질 낮음 — 오류·이상치·결측의 정제
- 관련 없는 특성 — 특성 공학으로 대응
> 토론거리: 특정 도로에 몰린 관측치로 제주 전체를 설명할 수 있는가.

## 과대적합과 과소적합
- 너무 단순 — 과소적합
- 너무 복잡 — 과대적합
- 잡음까지 외운 결과
- 규제: 복잡도에 제약
  - 강도는 하이퍼파라미터

## 테스트와 검증
- 일반화 성능은 새 데이터로만 측정 — 훈련과 테스트를 분리
- 테스트로 모델을 고르면 테스트에 과대적합
  - 선택·튜닝용 검증 세트를 따로 확보
- 검증 세트가 작을 때: 교차 검증으로 여러 번 평가
> 검증 세트는 개발 세트라고도 부른다. 공짜 점심 없음 정리는 구두로만.
