# 교과목 개요

## 교과목 개요
모빌리티 및 스마트시티 분야에서 활용되는 AI·ML의 기본 개념을 익히고,
실제 데이터를 활용한 분석과 모델 학습을 수행

## 이 과목의 세 단계
- 3~5주: scikit-learn으로 기계학습 모델 사용
  - 『핸즈온 머신러닝 3판』 Ch1·2·3(발췌)·4·6·7
- 6~11주: numpy로 신경망의 주요 연산 구현
  - 『밑바닥부터 시작하는 딥러닝 1』 Ch2~8
- 12~14주: 수요 예측·ETA·강화학습 적용
> 모델 사용 → 주요 연산 구현 → 교통 문제 적용

## 모빌리티 트랙에서의 위치
- 2학년: ML·DL 기초와 교통 응용
- 3학년: 알고리즘과 시뮬레이션

## 다루지 않는 것
- 최적화·라우팅·배차, 시뮬레이션 구축: 「스마트 교통물류」
- LLM·RAG·AI 에이전트: 별도 과목
- RNN·Transformer: ETA 사례에서 개념만 소개
- 객체탐지: 실습 제외, CNN 원리까지
> 한 학기 안에서 ML·DL 기초와 예측 문제에 집중

# AI 모빌리티 개관

## 자율주행 — 인지·판단·제어
- 인지: 카메라·라이다 기반 차선·객체 인식
- 판단: 주변 차량의 움직임 예측과 행동 선택
- 제어: 조향·가감속 명령
- 수업 범위: 11주차 CNN 원리와 구현
> 자율주행 전체 시스템 개발은 수업 범위에서 제외

## 수요응답형 교통(DRT)
- 고정 노선 대신 호출 수요에 맞춘 차량 운행
- 활용 지역: 농어촌·신도시 등 수요가 분산된 지역
- 예측 문제: 언제, 어디에서 호출이 발생하는가
- 운영 문제: 차량을 어디에 배치하는가
> 12주차 수요 예측과 3학년 배차 최적화의 차이

## MaaS와 통합 모빌리티
- 여러 이동수단의 검색·예약·결제를 하나의 서비스로 통합
  - 대중교통 + 공유자전거 + 호출 서비스
- 경로 추천에 필요한 구간별 소요시간
- 13주차 주제: ETA 예측
> 환승 경로 추천에 앞서 필요한 각 구간의 소요시간 예측

## AI가 실제로 쓰이는 지점
- 서비스별 예측·의사결정 문제
- 관련 수업: 11~14주차

표: 모빌리티 서비스와 주차별 대응
| 서비스 | AI가 푸는 문제 | 이 과목의 주차 |
|---|---|---|
| 내비게이션·지도 | 도착시각 예측 | 13주 (ETA) |
| 호출 앱·DRT | 수요 예측 | 12주 |
| 신호제어·배차 운영 | 순차 의사결정 | 14주 (RL) |
| 자율주행 인지 | 객체 인식 | 11주 (CNN) |
> 각 응용 사례를 뒤의 주차별 계획과 연결

# 15주 로드맵

## 15주 전체 구성
![15주 구성 — ML → DL → 교통 응용 → 팀 프로젝트 발표](fig_roadmap.png)

## ML 파트 (3~5주)
