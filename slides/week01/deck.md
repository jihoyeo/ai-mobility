# 이 과목에서 배우는 것

## 수업의 목표

- 데이터를 읽고 문제를 정의한다
- ML·DL 모델을 학습하고 평가한다
- 버스 도착시간 예측에 적용한다

> 마지막 프로젝트를 먼저 보여 준 뒤, 그 문제를 풀기 위해 무엇을 배우는지 역순으로 설명합니다.

## 모빌리티에서 다루는 문제

| 데이터 | 예측 |
|---|---|
| 버스 운행 이력 | 도착시간 |
| 대중교통 이용 이력 | 시간대별 수요 |
| 링크 속도·GPS | 통행시간 |
| 공유모빌리티 이력 | 대여·반납 수요 |

> 학생들에게 이 가운데 직접 써 본 서비스가 무엇인지 묻고 시작합니다.

## 이번 학기의 프로젝트

- 서울시 BIS 버스 운행 데이터
- 노선별 도착시간 예측
- XGBoost·MLP·Transformer 비교
- 날짜 순서에 따른 평가와 오차 분석

> 모델 이름을 자세히 설명하지 않습니다. 같은 문제를 여러 방법으로 풀고 공정하게 비교하는 것이 목표라고 안내합니다.

# 수업 진행

## 15주 구성

![15주 구성 — ML → DL → Transformer → ETA 프로젝트](fig_roadmap.png)

> ML의 기본부터 시작해 신경망과 Transformer를 배운 뒤, 마지막에 버스 ETA 문제로 돌아옵니다.

## 교재와 실습 코드

- 2~5주: 『핸즈온 머신러닝 3판』
- 6~7·10주: 『밑바닥부터 시작하는 딥러닝 1』
- 11~12주: Attention·Transformer 강의노트
- 실습: 교재의 공개 코드를 직접 실행

> 슬라이드만으로 수업하지 않습니다. 책을 펴고 설명한 뒤, 교재 저장소의 노트북을 함께 실행합니다.

## 수업에서 하는 일

- 화요일: 교재의 개념과 그림을 함께 읽기
- 수요일: 교재 코드를 실행하고 결과 확인하기
- 과제: 같은 방법을 교통 데이터에 적용하기

> 파이썬 문법을 외우는 수업이 아니라, 코드를 읽고 결과가 맞는지 판단하는 수업이라고 설명합니다.
