## 1.1 머신러닝이란?

머신러닝은 **데이터에서 학습하도록 컴퓨터를 프로그래밍하는 과학(또는 예술)**이다. 교재는 두 개의 고전적 정의를 인용한다.

> 머신러닝은 명시적인 프로그래밍 없이 컴퓨터가 학습하는 능력을 갖추게 하는 연구 분야.
> — 아서 새뮤얼(Arthur Samuel), 1959

> 어떤 작업 T에 대한 컴퓨터 프로그램의 성능을 P로 측정했을 때 경험 E로 인해 성능이 향상됐다면, 이 컴퓨터 프로그램은 작업 T와 성능 측정 P에 대해 경험 E로 학습한 것이다.
> — 톰 미첼(Tom Mitchell), 1997

스팸 필터를 이 정의에 대입하면 다음과 같다.

| 미첼의 정의 | 스팸 필터 |
|---|---|
| 작업 T | 새로운 메일이 스팸인지 구분 |
| 경험 E | 훈련 데이터 |
| 성능 측정 P | 정확도(accuracy) 등 직접 정의해야 하는 지표 |

### 기본 용어

| 용어 | 원어 | 의미 |
|---|---|---|
| 훈련 세트 | training set | 시스템이 학습에 사용하는 샘플 전체 |
| 훈련 사례 / 샘플 | training instance / sample | 훈련 세트의 개별 데이터 하나 |
| 모델 | model | 학습하고 예측을 만드는 부분 (신경망, 랜덤 포레스트 등) |

> **주의.** 위키백과 문서를 전부 내려받는다고 해서 컴퓨터가 어떤 작업을 갑자기 더 잘하게 되는 것은 아니다. 성능 향상이 없으면 머신러닝이 아니다.

## 1.2 왜 머신러닝을 사용하나요?

전통적인 프로그래밍으로 스팸 필터를 만들면 다음 절차를 반복한다.

1. 스팸에 자주 나타나는 단어와 구절(`4U`, `신용카드`, `무료`, `광장한`)을 사람이 조사한다.
2. 그 패턴을 감지하는 규칙을 직접 작성한다.
3. 테스트하고, 성능이 나올 때까지 1~2단계를 반복한다.

문제가 어렵기 때문에 규칙이 점점 길고 복잡해지며 유지 보수가 매우 힘들어진다(그림 1-1).

반면 머신러닝 기반 필터는 스팸에 자주 나타나는 패턴을 **자동으로 학습**하므로 프로그램이 훨씬 짧아지고 유지 보수가 쉬우며 대부분 정확도가 더 높다(그림 1-2).

### 자동으로 변화에 적응한다

스팸 발송자가 `4U` 대신 `For U`를 쓰기 시작하면, 전통적 필터는 사람이 규칙을 고쳐야 한다. 머신러닝 기반 필터는 사용자가 스팸으로 지정한 메일에 `For U`가 자주 나타나는 것을 스스로 인식하고 별도 작업 없이 분류한다(그림 1-3).

### 머신러닝을 통해 배운다

머신러닝 알고리즘이 학습한 것을 조사할 수 있다. 스팸 필터를 충분히 훈련하면 스팸을 예측하는 데 가장 좋은 단어와 단어 조합이 무엇인지 확인할 수 있다. 예상치 못한 상관관계나 새로운 추세가 발견되어 문제 자체를 더 잘 이해하게 되기도 한다. 대용량 데이터를 분석하여 숨겨진 패턴을 발견하는 것을 **데이터 마이닝**(data mining)이라 한다(그림 1-4).

### 머신러닝이 뛰어난 분야 (교재 요약)

- 기존 솔루션으로는 많은 수동 조정과 규칙이 필요한 문제 → 코드가 간단해지고 성능도 더 낫다
- 전통적인 방식으로는 해결 방법이 없는 복잡한 문제
- 유동적인 환경 → 새로운 데이터로 쉽게 재훈련할 수 있어 항상 최신 상태를 유지
- 복잡한 문제와 대량의 데이터에서 인사이트 얻기

> **모빌리티 적용.** 버스 도착시간(ETA)은 첫 번째와 세 번째 항목에 정확히 해당한다. "정류장 간 평균 소요시간 × 남은 정류장 수" 같은 규칙 기반 추정은 시간대·요일·사고·신호 지연을 규칙으로 계속 덧붙여야 하고, 노선이 바뀌면 다시 손봐야 한다.

## 1.3 애플리케이션 사례

교재가 제시하는 작업 유형과 대응 기술이다. 괄호 안은 해당 기법을 다루는 장이다.

| 사례 | 작업 유형 | 기술 |
|---|---|---|
| 생산 라인의 제품 이미지 자동 분류 | 이미지 분류 | CNN(14장), 트랜스포머(16장) |
| 뇌 스캔에서 종양 진단 | 시맨틱 분할 | CNN, 트랜스포머 |
| 뉴스 기사 자동 분류 | 텍스트 분류(NLP) | RNN, CNN, 트랜스포머(16장) |
| 부정적 코멘트 자동 구분 | 텍스트 분류 | NLP 도구 |
| 긴 문서 자동 요약 | 텍스트 요약 | NLP 도구 |
| 챗봇·개인 비서 | NLU + 질문–답변 | 여러 NLP 컴포넌트 |
| **내년도 수익 예측** | **회귀** | **선형 회귀, 다항 회귀(4장), 회귀 SVM(5장), 회귀 랜덤 포레스트(7장), 인공 신경망(10장). 시퀀스로 다루려면 RNN·CNN·트랜스포머(15·16장)** |
| 음성 명령 반응 | 음성 인식 | RNN, CNN, 트랜스포머 |
| 신용카드 부정 거래 감지 | 이상치 탐지 | 아이솔레이션 포레스트, 가우스 혼합(9장), 오토인코더(17장) |
| 고객 세분화 | 군집 | k-평균, DBSCAN(9장) |
| 고차원 데이터 시각화 | 데이터 시각화 | 차원 축소(8장) |
| 상품 추천 | 추천 시스템 | 인공 신경망(10장) |
| 지능형 게임 봇 | 강화 학습 | RL(18장) |

> **모빌리티 적용.** 통행시간·통행속도·ETA는 모두 굵게 표시한 **회귀**에 속한다. 이 수업은 회귀 행을 왼쪽에서 오른쪽으로 (선형회귀 → 랜덤 포레스트 → 신경망 → 트랜스포머) 그대로 따라간다.

## 1.4 머신러닝 시스템의 종류

교재는 세 가지 축으로 분류한다. 이 범주들은 서로 배타적이지 않고 원하는 대로 연결할 수 있다.

1. 훈련 지도 방식 (지도 / 비지도 / 준지도 / 자기 지도 / 강화 학습)
2. 실시간으로 점진적인 학습을 하는지 여부 (온라인 학습 / 배치 학습)
3. 데이터 포인트를 비교하는지, 패턴을 발견해 예측 모델을 만드는지 (사례 기반 / 모델 기반)

예를 들어 심층 신경망으로 실시간 학습하는 최첨단 스팸 필터는 "온라인 + 모델 기반 + 지도 학습" 시스템이다.

### 1.4.1 훈련 지도 방식

#### 지도 학습 (supervised learning)

알고리즘에 주입하는 훈련 데이터에 **레이블**(label)이라는 원하는 답이 포함된다.

- **분류**(classification): 스팸 필터가 전형적인 예. 샘플 이메일과 클래스(스팸/아님)로 훈련된다.
- **회귀**(regression): 특성(주행 거리, 연식, 브랜드 등)을 사용해 중고차 가격 같은 **타깃** 수치를 예측한다.

> **NOTE(교재).** 타깃과 레이블은 일반적으로 동의어로 취급되지만, 타깃은 회귀에서, 레이블은 분류에서 많이 쓰인다. 특성은 예측 변수(predictor)나 속성(attribute)이라고도 부른다.

일부 회귀 알고리즘은 분류에, 일부 분류 알고리즘은 회귀에 쓸 수 있다. 예컨대 **로지스틱 회귀**는 클래스에 속할 확률(예: 스팸일 가능성 20%)을 출력한다.

#### 비지도 학습 (unsupervised learning)

훈련 데이터에 레이블이 없다. 시스템이 아무런 도움 없이 학습해야 한다.

| 기법 | 설명 |
|---|---|
| 군집(clustering) | 비슷한 샘플을 그룹으로 묶는다. 계층 군집으로 더 작은 그룹으로 세분화할 수 있다 |
| 시각화(visualization) | 레이블 없는 고차원 데이터를 2D·3D 표현으로 만든다 (그림 1-9의 t-SNE) |
| 차원 축소(dimensionality reduction) | 정보를 크게 잃지 않으면서 데이터를 간소화한다. 상관관계가 있는 여러 특성을 하나로 합치는 것을 **특성 추출**(feature extraction)이라 한다 |
| 이상치 탐지(outlier detection) | 훈련 중 대부분 정상 샘플을 만나 이를 인식하도록 훈련되고, 새 샘플이 정상인지 판단한다 |
| 특이치 탐지(novelty detection) | 훈련 세트의 모든 샘플과 달라 보이는 새 샘플을 탐지한다. 감지 대상이 전혀 없는 "깨끗한" 훈련 세트가 필요하다 |
| 연관 규칙 학습 | 대량의 데이터에서 특성 간의 관계를 찾는다 (바비큐 소스+감자 → 스테이크) |

> **TIP(교재).** 지도 학습 알고리즘에 데이터를 주입하기 전에 차원 축소를 적용해 차원 수를 줄이면 실행 속도가 훨씬 빨라지고 디스크·메모리를 덜 쓴다. 경우에 따라 성능이 좋아지기도 한다.

#### 준지도 학습 (semi-supervised learning)

레이블을 다는 데 시간과 비용이 많이 들기 때문에, 레이블 없는 샘플이 많고 레이블된 샘플은 적은 경우가 많다. 구글 포토가 예시다. 사진에서 같은 사람을 자동으로 묶는 것은 비지도 학습(군집)이고, 사람마다 레이블을 하나만 추가하면 모든 사진에 이름을 붙일 수 있다. 대부분의 준지도 학습 알고리즘은 지도 학습과 비지도 학습의 조합이다.

#### 자기 지도 학습 (self-supervised learning)

레이블이 전혀 없는 데이터셋에서 레이블이 완전히 부여된 데이터셋을 **생성**한다. 예를 들어 이미지의 일부를 랜덤하게 마스킹하고 원본을 복원하도록 훈련한다. 마스킹된 이미지가 입력, 원본이 레이블이다(그림 1-12).

훈련된 모델 자체도 유용하지만(손상 복원, 객체 삭제), 보통은 실제 관심 작업을 위해 모델을 수정하거나 **미세 튜닝**(fine tuning)한다. 한 작업에서 다른 작업으로 지식을 전달하는 것을 **전이 학습**(transfer learning)이라 한다.

> 교재는 자기 지도 학습을 비지도 학습의 일부가 아니라 **별개의 범주**로 다루는 것이 가장 좋다고 정리한다. 훈련 중 (생성된) 레이블을 사용하고, 초점이 지도 학습과 동일한 작업(주로 분류와 회귀)에 있기 때문이다.

#### 강화 학습 (reinforcement learning)

학습하는 시스템을 **에이전트**라 하며, **환경**을 관찰해 **행동**을 실행하고 그 결과로 **보상**(또는 벌점)을 받는다. 시간이 지나면서 가장 큰 보상을 얻기 위한 최상의 전략인 **정책**(policy)을 스스로 학습한다(그림 1-13).

알파고는 수백만 개의 게임을 분석하고 자기 자신과 대국하며 학습했고, 실제 대국 때는 학습 기능을 끄고 학습한 전략을 적용했다. 이를 **오프라인 학습**이라 한다.

### 1.4.2 배치 학습과 온라인 학습

입력 데이터의 스트림으로부터 점진적으로 학습할 수 있는지 여부에 따른 구분이다.

#### 배치 학습 (batch learning)

가용한 데이터를 모두 사용해 훈련시켜야 하며, 시간과 자원을 많이 쓰므로 보통 오프라인에서 수행한다. 훈련 후에는 학습 없이 적용만 하므로 **오프라인 학습**이라고도 한다.

모델 성능은 시간이 지남에 따라 천천히 감소하는 경향이 있다. 세상은 계속 진화하는데 모델은 그대로이기 때문이며, 이를 **모델 부패**(model rot) 또는 **데이터 드리프트**(data drift)라 한다. 해결책은 최신 데이터로 정기적으로 재훈련하는 것이다. 재훈련 주기는 문제에 따라 다르다. 고양이/강아지 분류는 매우 느리게 감소하지만 금융 시장 예측은 매우 빠르게 나빠진다.

배치 학습의 한계:

- 전체 데이터셋으로 훈련하는 데 몇 시간이 걸릴 수 있다. 보통 24시간마다 또는 매주 훈련한다
- 많은 컴퓨팅 자원이 필요하다 (CPU, 메모리, 디스크, 디스크 IO, 네트워크 IO)
- 자원이 제한된 시스템(스마트폰, 화성 탐사 로버)이 스스로 학습해야 할 때 심각한 문제가 된다

#### 온라인 학습 (online learning)

데이터를 순차적으로 한 개씩 또는 **미니배치**(mini-batch) 단위로 주입하여 훈련한다. 매 학습 단계가 빠르고 비용이 적게 들어 데이터가 도착하는 대로 즉시 학습할 수 있다(그림 1-14).

컴퓨터 한 대의 메인 메모리에 들어갈 수 없는 아주 큰 데이터셋에도 쓸 수 있다. 이를 **외부 메모리 학습**(out-of-core learning)이라 한다.

> **CAUTION(교재).** 외부 메모리 학습은 보통 오프라인으로 실행된다. 그래서 "온라인 학습"이란 이름이 혼란을 줄 수 있다. **점진적 학습**(incremental learning)이라고 생각하자.

**학습률**(learning rate)이 중요한 파라미터다.

| 학습률 | 결과 |
|---|---|
| 높음 | 데이터에 빠르게 적응하지만 예전 데이터를 금방 잊어버린다 |
| 낮음 | 관성이 커져 더 느리게 학습하지만, 잡음이나 대표성 없는 데이터 포인트에 덜 민감해진다 |

가장 큰 문제점은 나쁜 데이터가 주입되면 성능이 감소한다는 점이다. 버그(로봇의 오작동 센서)나 시스템을 속이려는 행위(검색 엔진 스팸)에서 나쁜 데이터가 올 수 있다. 시스템을 면밀히 모니터링하고 성능 감소가 감지되면 즉각 학습을 중지시켜야 한다(가능하면 이전 운영 상태로 되돌린다). 이상치 탐지 알고리즘(9장)으로 입력을 모니터링할 수도 있다.

> **모빌리티 적용.** 이 수업의 실습과 프로젝트는 재현 가능한 비교를 위해 **배치 학습**을 사용한다. 다만 BIS 데이터는 계절·공사·노선 개편으로 드리프트가 발생하므로, 날짜 기준 분할(3주차)과 시간대별 오차 분석(14주차)에서 이 개념을 다시 사용한다.

### 1.4.3 사례 기반 학습과 모델 기반 학습

어떻게 **일반화**(generalization)되는가에 따른 구분이다. 훈련 데이터에서 높은 성능을 내는 것이 전부가 아니며, 진짜 목표는 새로운 샘플에 잘 작동하는 모델이다.

#### 사례 기반 학습 (instance-based learning)

시스템이 훈련 샘플을 **기억**함으로써 학습한다. 그리고 **유사도 측정**을 사용해 새로운 데이터와 학습한 샘플을 비교하는 식으로 일반화한다. 그림 1-16에서 새로운 샘플은 가장 비슷한 샘플 중 다수가 삼각형이므로 삼각형으로 분류된다.

#### 모델 기반 학습 (model-based learning)

샘플들의 모델을 만들어 **예측**에 사용한다(그림 1-17).

교재는 OECD 더 나은 삶의 지표와 세계 은행의 1인당 GDP를 합쳐 예제를 만든다.

| 국가 | 1인당 GDP(US 달러) | 삶의 만족도 |
|---|---:|---:|
| 튀르키예 | 28,384 | 5.5 |
| 헝가리 | 31,008 | 5.6 |
| 프랑스 | 42,026 | 6.5 |
| 미국 | 60,236 | 6.9 |
| 뉴질랜드 | 42,404 | 7.3 |
| 호주 | 48,698 | 7.3 |
| 덴마크 | 55,938 | 7.6 |

데이터가 흩어져 있지만 삶의 만족도는 1인당 GDP가 증가할수록 거의 선형으로 상승한다. 1인당 GDP의 선형 함수로 모델링하기로 하는 이 단계를 **모델 선택**(model selection)이라 한다.

**식 1-1 간단한 선형 모델**

```
삶의_만족도 = θ₀ + θ₁ × 1인당_GDP
```

θ₀와 θ₁은 **모델 파라미터**(model parameter)다. 이 값을 조정하면 어떤 선형 함수든 표현할 수 있다(그림 1-19).

최상의 값을 찾으려면 측정 지표를 정해야 한다. 얼마나 좋은지 측정하는 **효용 함수**(utility function, 또는 적합도 함수)를 정의하거나, 얼마나 나쁜지 측정하는 **비용 함수**(cost function)를 정의한다. 선형 회귀에서는 보통 예측과 훈련 데이터 사이의 거리를 재는 비용 함수를 쓰고, 이 거리를 최소화하는 것이 목표다.

**선형 회귀** 알고리즘에 훈련 데이터를 공급하면 데이터에 가장 잘 맞는 파라미터를 찾는다. 이를 모델을 **훈련**(training)시킨다고 한다. 이 경우 최적 파라미터는 θ₀ = 3.75, θ₁ = 6.78×10⁻⁵ 였다.

> **CAUTION(교재).** '모델'이라는 단어는 (1) 모델의 종류(예: 선형 회귀), (2) 완전히 정의된 모델 구조(예: 입력 하나와 출력 하나를 가진 선형 회귀), (3) 예측에 사용하기 위해 준비된 훈련된 최종 모델(예: θ₀ = 3.75, θ₁ = 6.78×10⁻⁵인 선형 회귀) 중 어느 것이든 의미할 수 있다. **모델 선택**은 (1)이나 (2)를 고르는 것이고, **모델 훈련**은 (3)을 얻기 위해 알고리즘을 실행하는 것이다.

키프로스의 1인당 GDP는 37,655달러이므로 3.75 + 37,655 × 6.78×10⁻⁵ = 6.30이라는 삶의 만족도를 계산한다.

```python
import matplotlib.pyplot as plt
import pandas as pd
from sklearn.linear_model import LinearRegression

# 데이터를 다운로드하고 준비합니다.
data_root = "https://github.com/ageron/data/raw/main/"
lifesat = pd.read_csv(data_root + "lifesat/lifesat.csv")
X = lifesat[["GDP per capita (USD)"]].values
y = lifesat[["Life satisfaction"]].values

# 데이터를 그래프로 나타냅니다.
lifesat.plot(kind='scatter', grid=True,
             x="GDP per capita (USD)", y="Life satisfaction")
plt.axis([23_500, 62_500, 4, 9])
plt.show()

# 선형 모델을 선택합니다.
model = LinearRegression()

# 모델을 훈련합니다.
model.fit(X, y)

# 키프로스에 대해 예측을 만듭니다.
X_new = [[37_655.2]]           # 2020년 키프로스 1인당 GDP
print(model.predict(X_new))    # 출력: [[6.30165767]]
```

사례 기반 알고리즘으로 바꾸려면 두 줄만 고치면 된다.

```python
from sklearn.neighbors import KNeighborsRegressor
model = KNeighborsRegressor(n_neighbors=3)
```

> **NOTE(교재).** k-최근접 이웃 회귀는 키프로스와 GDP가 가장 가까운 세 나라(이스라엘 7.2, 리투아니아 5.9, 슬로베니아)의 평균을 구해 6.33을 예측한다. 모델 기반 예측 6.30과 매우 비슷하다.

### 전형적인 머신러닝 프로젝트의 형태 (교재 요약)

1. 데이터를 분석한다.
2. 모델을 선택한다.
3. 훈련 데이터로 모델을 훈련시킨다(학습 알고리즘이 비용 함수를 최소화하는 파라미터를 찾는다).
4. 잘 일반화되기를 기대하면서 새로운 데이터에 모델을 적용해 예측을 만든다. 이를 **추론**(inference)이라 한다.

## 1.5 머신러닝의 주요 도전 과제

문제가 될 수 있는 것은 **'나쁜 모델'과 '나쁜 데이터'** 두 가지다.

### 1.5.1 충분하지 않은 양의 훈련 데이터

아주 간단한 문제에서도 수천 개의 데이터가 필요하고, 이미지나 음성 인식 같은 복잡한 문제라면 수백만 개가 필요할지도 모른다.

> **믿기 힘든 데이터의 효과 (교재 박스).** 미셸 반코와 에릭 브릴은 2001년 논문에서 충분한 데이터가 주어지면 아주 간단한 모델을 포함해 여러 다른 머신러닝 알고리즘이 복잡한 자연어 중의성 해소 문제를 거의 비슷하게 잘 처리한다는 사실을 보여주었다(그림 1-21). 이 생각은 2009년 피터 노빅 등의 「The Unreasonable Effectiveness of Data」 논문으로 더 유명해졌다.
>
> 다만 교재는 곧바로 단서를 단다. **소규모 또는 중간 규모의 데이터셋이 매우 흔하고, 훈련 데이터를 추가로 모으는 것이 항상 쉽거나 저렴하지 않으므로 아직은 알고리즘을 무시하지 말아야 한다.**

### 1.5.2 대표성 없는 훈련 데이터

일반화가 잘되려면 훈련 데이터가 일반화하고 싶은 새로운 사례를 잘 **대표**해야 한다. 앞의 선형 모델은 1인당 GDP가 23,500달러보다 적거나 62,500달러보다 많은 나라가 빠져 있어 대표성이 완벽하지 못했다. 누락된 나라를 추가하면 모델이 크게 바뀌고, 간단한 선형 모델은 잘 작동하지 않는다는 것이 드러난다(그림 1-22).

| 용어 | 의미 |
|---|---|
| 샘플링 잡음(sampling noise) | 샘플이 작아서 우연에 의해 생기는 대표성 없는 데이터 |
| 샘플링 편향(sampling bias) | 표본 추출 방법이 잘못되어 큰 샘플에서도 대표성을 띠지 못하는 것 |

> **유명한 샘플링 편향 사례 (교재 박스).** 1936년 미국 대통령 선거에서 『The Literary Digest』는 천만 명에게 우편물을 보내 240만 명의 응답을 받고 랜던의 57% 득표를 예측했지만 루스벨트가 62%로 당선되었다. 원인은 두 가지였다. 첫째, 주소를 전화번호부·자사 구독자 명부·클럽 회원 명부에서 얻어 공화당에 투표할 가능성이 높은 부유한 계층에 편중되었다. 둘째, 우편물 수신자 중 25% 미만만 응답했다. 이런 종류의 편향을 **비응답 편향**(nonresponse bias)이라 한다.

> **모빌리티 적용.** BIS 데이터에서 특정 기간(방학, 명절)이나 특정 시간대만 뽑아 훈련하면 그대로 샘플링 편향이 된다. 노선 선정 시 운행 횟수와 결측률을 기준으로 삼는 이유가 여기에 있다.

### 1.5.3 낮은 품질의 데이터

훈련 데이터가 오류, 이상치, 잡음으로 가득하면 시스템이 내재된 패턴을 찾기 어렵다. 훈련 데이터 정제에 시간을 투자할 가치가 충분하다.

- 일부 샘플이 명확히 이상치라면 그냥 무시하거나 수동으로 고치는 것이 좋다.
- 일부 샘플에 특성 몇 개가 빠져 있다면(예: 고객 중 5%가 나이를 기록하지 않음) 이 특성을 모두 무시할지, 이 샘플들을 무시할지, 빠진 값을 채울지(예: 평균 나이), 또는 이 특성을 넣은 모델과 제외한 모델을 따로 훈련시킬지 결정해야 한다.

### 1.5.4 관련없는 특성

> 엉터리가 들어가면 엉터리가 나온다(garbage in, garbage out).

성공적인 머신러닝 프로젝트의 핵심 요소는 훈련에 사용할 좋은 특성을 찾는 것이며, 이 과정을 **특성 공학**(feature engineering)이라 한다.

| 작업 | 설명 |
|---|---|
| 특성 선택(feature selection) | 가지고 있는 특성 중에서 훈련에 가장 유용한 특성을 선택 |
| 특성 추출(feature extraction) | 특성을 결합해 더 유용한 특성을 만듦 (차원 축소 알고리즘이 도움이 됨) |
| 데이터 수집 | 새로운 데이터를 수집해 새 특성을 만듦 |

### 1.5.5 훈련 데이터 과대적합

**과대적합**(overfitting)은 모델이 훈련 데이터에는 너무 잘 맞지만 일반성이 떨어지는 것이다. 교재는 "해외 여행 중 택시 운전사가 물건을 훔쳤다고 해서 그 나라 모든 택시 운전사를 도둑이라 생각하는 것"에 비유한다.

심층 신경망 같은 복잡한 모델은 미묘한 패턴을 감지할 수 있지만, 훈련 세트에 잡음이 많거나 데이터셋이 너무 작으면 잡음이 섞인 패턴을 감지하게 된다. 교재의 예시가 인상적이다. 나라 이름 같은 관련없는 특성을 많이 추가하면, 복잡한 모델은 이름에 `w`가 들어간 나라의 삶의 만족도가 7보다 크다는 패턴을 감지할지 모른다(뉴질랜드 7.6, 노르웨이 7.3, 스웨덴 7.2, 스위스 7.5). **이 패턴이 진짜인지 잡음 때문인지 모델이 구분해낼 방법은 없다.**

> **CAUTION(교재).** 과대적합은 훈련 데이터의 양과 잡음에 비해 모델이 너무 복잡할 때 일어난다. 해결 방법은 다음과 같다.
> - 파라미터 수가 적은 모델을 선택하거나(예: 고차원 다항 모델보다 선형 모델), 훈련 데이터에 있는 특성 수를 줄이거나, 모델에 제약을 가하여 단순화시킨다.
> - 훈련 데이터를 더 많이 모은다.
> - 훈련 데이터의 잡음을 줄인다(예: 오류 데이터 수정과 이상치 제거).

모델을 단순하게 하고 과대적합 위험을 줄이기 위해 모델에 제약을 가하는 것을 **규제**(regularization)라 한다. 선형 모델의 두 파라미터 θ₀, θ₁은 두 개의 **자유도**(degree of freedom)를 학습 알고리즘에 부여한다. θ₁ = 0을 강제하면 자유도가 하나만 남아 결국 평균 근처가 된다. θ₁을 수정하도록 허락하되 작은 값을 갖도록 유지하면 자유도 1과 2 사이의 적절한 어딘가에 위치한다. **데이터에 완벽히 맞추는 것과 일반화를 위해 단순한 모델을 유지하는 것 사이의 올바른 균형을 찾는 것이 좋다.**

적용할 규제의 양은 **하이퍼파라미터**(hyperparameter)가 결정한다. 하이퍼파라미터는 (모델이 아니라) **학습 알고리즘의 파라미터**다. 학습 알고리즘으로부터 영향을 받지 않으며, 훈련 전에 미리 지정되고, 훈련하는 동안에는 상수로 남아 있다.

### 1.5.6 훈련 데이터 과소적합

**과소적합**(underfitting)은 과대적합의 반대로, 모델이 너무 단순해서 데이터의 내재된 구조를 학습하지 못할 때 일어난다. 해결 기법은 다음과 같다.

- 모델 파라미터가 더 많은 강력한 모델을 선택한다.
- 학습 알고리즘에 더 좋은 특성을 제공한다(특성 공학).
- 모델의 제약을 줄인다(예: 규제 하이퍼파라미터를 감소시킨다).

### 1.5.7 핵심 요약 (교재 원문 구성)

- 머신러닝은 명시적인 규칙을 코딩하지 않고 기계가 데이터로부터 학습하여 어떤 작업을 더 잘하도록 만드는 것이다.
- 여러 종류의 머신러닝 시스템이 있다. 지도 학습과 비지도 학습, 배치 학습과 온라인 학습, 사례 기반 학습과 모델 기반 학습 등이다.
- 머신러닝 프로젝트에서는 훈련 세트에 데이터를 모아 학습 알고리즘에 주입한다. 학습 알고리즘이 모델 기반이면 훈련 세트에 모델을 맞추기 위해 모델 파라미터를 조정하고, 새로운 데이터에서도 좋은 예측을 만들 거라 기대한다. 알고리즘이 사례 기반이면 샘플을 기억하는 것이 학습이고 유사도 측정을 사용하여 새로운 샘플에 일반화한다.
- 훈련 세트가 너무 작거나, 대표성이 없거나, 잡음이 많고 관련없는 특성으로 오염되어 있으면 시스템이 잘 작동하지 않는다. 마지막으로 모델이 너무 단순하거나(과소적합) 너무 복잡하지 않아야 한다(과대적합).

## 1.6 테스트와 검증

모델이 새로운 샘플에 얼마나 잘 일반화될지 알 수 있는 유일한 방법은 새로운 샘플에 실제로 적용해보는 것이다. 실제 서비스에 넣고 모니터링하는 방법도 있지만, 모델이 아주 나쁘면 고객이 불만을 토로한다.

더 나은 방법은 데이터를 **훈련 세트**와 **테스트 세트** 두 개로 나누는 것이다. 새로운 샘플에 대한 오차 비율을 **일반화 오차**(generalization error, 또는 외부 샘플 오차)라 하며, 테스트 세트에서 모델을 평가함으로써 이 오차에 대한 추정값을 얻는다.

> **훈련 오차가 작지만 일반화 오차가 크다면 이는 모델이 훈련 데이터에 과대적합되었다는 뜻이다.**

> **TIP(교재).** 보통 데이터의 80%를 훈련에, 20%를 테스트용으로 떼어놓는다. 하지만 이는 데이터셋 크기에 따라 다르다. 샘플이 천만 개일 때 1%를 떼어놓는다고 하면 테스트 세트에 100,000개의 샘플이 있다는 의미이고, 아마도 일반화 오차를 추정하는 데 충분한 크기일 것이다. (사이킷런 `train_test_split`의 기본값은 25%다.)

### 1.6.1 하이퍼파라미터 튜닝과 모델 선택

테스트 세트만으로 모델을 고르면 문제가 생긴다. 100개의 하이퍼파라미터 값으로 100개의 모델을 훈련시키고 일반화 오차가 가장 낮은 모델(5%)을 골라 실제 서비스에 투입했더니 오차가 15%가 되는 상황이 생긴다. **일반화 오차를 테스트 세트에서 여러 번 측정했으므로 모델과 하이퍼파라미터가 테스트 세트에 최적화된 모델을 만들었기 때문이다.**

일반적인 해결 방법은 **홀드아웃 검증**(holdout validation)이다(그림 1-25).

1. 훈련 세트의 일부를 떼어내 **검증 세트**(validation set, 개발 세트·데브 세트)를 만든다.
2. 줄어든 훈련 세트에서 다양한 하이퍼파라미터 값을 가진 여러 모델을 훈련한다.
3. 검증 세트에서 가장 높은 성능을 내는 모델을 선택한다.
4. 최선의 모델을 (검증 세트를 포함한) 전체 훈련 세트에서 다시 훈련하여 최종 모델을 만든다.
5. 최종 모델을 테스트 세트에서 평가하여 일반화 오차를 추정한다.

검증 세트 크기의 딜레마도 교재가 명시한다.

| 검증 세트 크기 | 문제 |
|---|---|
| 너무 작으면 | 모델이 정확하게 평가되지 않아 최적이 아닌 모델을 잘못 선택할 수 있다 |
| 너무 크면 | 남은 훈련 세트가 전체 훈련 세트보다 훨씬 작아진다. 최종 모델은 전체 훈련 세트에서 훈련되므로, 너무 작은 훈련 세트에서 훈련한 후보 모델을 비교하는 것은 이상적이지 않다 (마라톤에 참여하기 위해 가장 빠른 단거리 주자를 고르는 것과 같다) |

해결책은 작은 검증 세트를 여러 개 사용해 반복적으로 **교차 검증**(cross-validation)을 수행하는 것이다. 검증 세트마다 나머지 데이터에서 훈련한 모델을 해당 검증 세트에서 평가하고, 모든 평가를 평균하면 훨씬 정확한 성능을 측정할 수 있다. 단점은 훈련 시간이 검증 세트 개수에 비례해 늘어난다는 점이다.

### 1.6.2 데이터 불일치

훈련 데이터를 쉽게 많이 얻을 수 있지만 그 데이터가 실제 제품에 사용될 데이터를 완벽하게 대표하지 못하는 경우가 있다. 웹에서 내려받은 꽃 사진 수백만 장과 모바일 앱으로 실제 찍은 사진 10,000장이 그 예다.

가장 중요한 규칙은 **검증 세트와 테스트 세트가 실전에서 기대하는 데이터를 가능한 한 잘 대표해야 한다**는 것이다. 따라서 검증 세트와 테스트 세트는 대표성을 가진 (모바일 앱) 사진으로만 구성되어야 한다.

이때 성능이 나쁘면 원인이 과대적합인지 데이터 불일치인지 알기 어렵다. 앤드루 응의 해결책은 웹 사진 훈련 세트의 일부를 떼어내 **훈련-개발 세트**(train-dev set)를 만드는 것이다(그림 1-26).

| 훈련-개발 세트 성능 | 검증 세트 성능 | 진단 | 대응 |
|---|---|---|---|
| 나쁨 | — | 훈련 세트에 과대적합 | 모델 규제, 데이터 추가, 훈련 데이터 정제 |
| 좋음 | 나쁨 | 데이터 불일치 | 웹 이미지를 모바일 앱 사진처럼 보이도록 전처리한 뒤 재훈련 |

> **공짜 점심 없음 이론 (교재 박스).** 모델은 데이터의 간소화된 표현이며, 특정 종류의 모델을 선택할 때 데이터에 대한 암묵적인 **가정**을 한다. 1996년 데이비드 월퍼트는 데이터에 관해 완벽하게 아무런 가정도 하지 않으면 한 모델을 다른 모델보다 선호할 근거가 없음을 보였다. 이를 **공짜 점심 없음**(no free lunch, NFL) 이론이라 한다. 어떤 모델이 최선인지 확실히 아는 유일한 방법은 모든 모델을 평가해보는 것뿐인데 이것이 불가능하므로, 실전에서는 데이터에 관해 타당한 가정을 하고 적절한 모델 몇 가지만 평가한다.

## 연습문제 (교재 원문, 1장 발췌)

1. 머신러닝을 어떻게 정의할 수 있나요?
2. 머신러닝이 도움을 줄 수 있는 문제 유형 네 가지를 말해보세요.
3. 레이블된 훈련 세트란 무엇인가요?
4. 가장 널리 사용되는 지도 학습 작업 두 가지는 무엇인가요?
5. 보편적인 비지도 학습 작업 네 가지는 무엇인가요?
6. 사전 정보가 없는 여러 지형에서 로봇을 걸어가게 하려면 어떤 종류의 머신러닝 알고리즘을 사용해야 하나요?
7. 고객을 여러 그룹으로 분할하려면 어떤 알고리즘을 사용해야 하나요?
8. 스팸 감지의 문제는 지도 학습과 비지도 학습 중 어떤 문제로 볼 수 있나요?
9. 온라인 학습 시스템이 무엇인가요?
10. 외부 메모리 학습이 무엇인가요?
11. 예측을 하기 위해 유사도 측정에 의존하는 학습 알고리즘은 무엇인가요?
12. 모델 파라미터와 학습 알고리즘의 하이퍼파라미터 사이에는 어떤 차이가 있나요?
13. 모델 기반 알고리즘이 찾는 것은 무엇인가요? 성공을 위해 이 알고리즘이 사용하는 가장 일반적인 전략은 무엇인가요? 예측은 어떻게 만드나요?
