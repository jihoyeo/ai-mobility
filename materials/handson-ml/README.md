# 핸즈온 머신러닝 강의노트

『핸즈온 머신러닝 3판』에서 AI 모빌리티 수업에 사용하는 범위의 장별 노트. **한 파일에 한 장**을 담으며, 교재의 절 번호와 그림·식 번호를 그대로 따른다.

| 주차 | 교재 범위 | 강의노트 | 주요 내용 |
|---|---|---|---|
| 2주차 | Ch1 (pp. 27~66) | [한눈에 보는 머신러닝](week02_ch01.md) | 시스템의 종류, 도전 과제, 테스트와 검증 |
| 3주차 | Ch2 (pp. 68~141) | [머신러닝 프로젝트 처음부터 끝까지](week03_ch02.md) | 문제 정의, 데이터 분할, EDA, 전처리 파이프라인, 교차 검증, 튜닝 |
| 4주차 | Ch3 발췌 (pp. 143~175) | [분류](week04_ch03.md) | 오차 행렬, 정밀도·재현율, 임곗값, PR·ROC 곡선, 오류 분석 |
| 4주차 | Ch4 (pp. 177~225) | [모델 훈련](week04_ch04.md) | 정규 방정식, 경사 하강법, 다항 회귀, 학습 곡선, 규제, 로지스틱·소프트맥스 |
| 5주차 | Ch6 (pp. 250~267) | [결정 트리](week05_ch06.md) | 지니 불순도, CART, 규제, 회귀 트리, 분산 문제 |
| 5주차 | Ch7 (pp. 268~296) | [앙상블 학습과 랜덤 포레스트](week05_ch07.md) | 투표, 배깅·OOB, Random Forest, 부스팅, HGB·XGBoost, 스태킹 |

## 노트 구성 규칙

- 각 파일은 교재의 **절 번호 순서**를 그대로 따르고, 교재의 NOTE·TIP·CAUTION 박스는 출처를 밝혀 그대로 옮긴다.
- 코드는 교재 예제를 그대로 싣고, 출력값도 교재의 값을 유지한다.
- `모빌리티 적용` 블록은 교재 내용이 아니라 **이 수업의 ETA 프로젝트로 옮길 때의 해석**이다.
- 각 장 끝에 교재 연습문제 원문과 수업용 확인 문제를 함께 둔다.

## 사용 방법

- 화요일 이론 수업: 개념과 코드 예제
- 수요일 실습: 노트의 실습 항목과 교재 노트북
- 과제: 교재 예제를 데이콘 제주 통행속도 데이터에 적용
- 공통 환경: Python, pandas, scikit-learn, matplotlib
