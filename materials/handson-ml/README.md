# 핸즈온 머신러닝 강의노트

『핸즈온 머신러닝 3판』에서 AI 모빌리티 수업에 사용하는 범위의 주차별 노트.

| 주차 | 교재 범위 | 강의노트 | 주요 내용 |
|---|---|---|---|
| 3주차 | Ch1·Ch2 | [머신러닝 개요와 End-to-End 프로젝트](week03_ch01_ch02.md) | 문제 정의, 데이터 분할, 전처리, 파이프라인, 검증, 튜닝 |
| 4주차 | Ch3 발췌·Ch4 | [분류 평가와 모델 훈련](week04_ch03_ch04.md) | 분류 지표, 경사하강법, 다항회귀, 규제, 로지스틱 회귀 |
| 5주차 | Ch6·Ch7 | [결정 트리와 앙상블](week05_ch06_ch07.md) | 결정 트리, Random Forest, 부스팅, XGBoost, 스태킹 |

## 사용 방법

- 화요일 이론 수업: 개념과 코드 예제
- 수요일 실습: 노트의 실습 항목과 교재 노트북
- 과제: 교재 예제를 모빌리티 데이터에 적용
- 공통 환경: Python, pandas, scikit-learn, matplotlib
